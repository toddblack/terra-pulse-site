# terra-pulse-site

The public pages for Terra Pulse, served by GitHub Pages at
<https://toddblack.github.io/terra-pulse-site/>. The app repos are private;
this one holds only what must be public:

- `privacy-android.md`: the Android app's privacy policy, linked from its
  Google Play listing. This is the only copy; edit it here.
- `index.md`: the landing page, which the app's user agent links to.
